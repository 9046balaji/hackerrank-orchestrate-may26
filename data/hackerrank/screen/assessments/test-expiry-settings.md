# How Long Do HackerRank Tests Stay Active?

Tests in HackerRank remain active indefinitely unless a start and end time are set. Without these settings, tests do not expire automatically.

## Setting expiration times
To set expiration, specify a start and end date/time in the test settings. After expiration:
- Invited candidates cannot access the test.
- The "Invite" button is disabled; no new invitations can be sent.

## How to check or change expiration settings
1. Go to the test's **Settings** and select the **General** section.
2. Update the **Start date & time** and **End date & time** fields as needed.
3. To keep the test active indefinitely, clear these fields by clicking the clear icon (X).

If the test has an expiration set, adjust these settings to enable new invitations.
