# Test Variants vs New Tests

## When to Use Test Variants
Create variants to adapt a single test to different candidate profiles, such as roles with different tech stacks (React, Angular, Vue.js). Variants streamline assessments by showing candidates only relevant sections and generating role-specific reports.

## Advantages of Test Variants
- Reduces the need to manage multiple tests, improving efficiency.
- Decreases maintenance while allowing scalable personalization.
- Ensures candidates are tested on relevant content.

## Disadvantages and Limitations
- A test must have at least two variants to function; you cannot delete a variant if only two exist.
- Variants without logic are hidden from candidates until logic is added.

## When to Create a New Test
Create a new test when the role, skill set, or evaluation criteria differ significantly enough that variants would not represent the position accurately.
