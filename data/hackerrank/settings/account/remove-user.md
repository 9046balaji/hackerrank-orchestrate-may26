# Removing a User from HackerRank

## Removing an interviewer
1. Log in to your HackerRank for Work account as an Admin.
2. Navigate to **Settings > Team** (or the **Interviewers** section).
3. Find the user you want to remove.
4. Click the **three-dot menu (⋮)** next to their name.
5. Select **Remove** or **Deactivate**.
6. Confirm the action in the dialog.

**Note:** If you do not see the remove option, ensure you have Admin privileges on the account. The option may not appear for users in certain roles.

## Removing an employee from a hiring account
1. Go to **Settings > Users** in your HackerRank for Work dashboard.
2. Locate the employee you want to remove.
3. Click the actions menu and select **Remove User**.
4. Confirm removal. The user will lose access immediately.
